# MoveScape

**Make art with your body.**

MoveScape watches how you move (via webcam, on-device) and translates the qualities of your movement — openness, speed, symmetry — into a living generative artwork that grows on screen while you move. When you finish, the piece is yours.

**Privacy:** all video processing happens on your device. Video never leaves your machine; the app has no backend at all.

## Status

Pre-alpha — milestone M0 (scaffold). Nothing to see yet.

## Development

```bash
npm install
npm run dev        # start the dev server
npm test           # run tests
npm run lint       # lint (includes the seeded-randomness invariant)
npm run typecheck  # type-check
npm run build      # production build
```
